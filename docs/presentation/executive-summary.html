Orientation · What is Haze?

A CUDA-shaped runtime for the Niobium FHE accelerator

A CUDA-shaped C ABI record-and-replay shim that drives the Niobium FHE accelerator.

  • Sits one layer below niobium-client.
  • Its CUDA shape lets GPU FHE libraries — for example FIDESlib — retarget with minimal porting.
  • A runtime shim: not an FHE application or compiler.

Model · record → flush → replay

Every call records an op; one flush materializes them

Authors write CUDA-like calls; each call records a Polynomial IR op rather than executing it.

  • hazeFlush is the sole materialization trigger.
  • The recorded trace is replayed locally for validation, or shipped to the Niobium compiler for hardware.

Priority 1 · Graph capture

Record-once, replay-many — the highest priority

  • Mirrors CUDA stream-capture / instantiate / launch.
  • Correctness invariant: stable device addresses across replays.
